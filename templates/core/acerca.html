Acerca del Sistema

HelpDesk — Sistema de Soporte Técnico Básico

Este sistema permite centralizar y gestionar incidentes o reportes de fallas técnicas en una oficina o universidad. Los usuarios pueden consultar el estado de los tickets, filtrar por estado y ver el detalle de cada reporte.

Características
  • Registro y gestión de tickets de soporte.
  • Clasificación por prioridad (Baja, Media, Alta).
  • Seguimiento de estado (Abierto, En Proceso, Resuelto).
  • Dashboard con resumen general.
  • Filtrado por estado mediante rutas dinámicas.
Tecnologías
  • Python & Django
  • SQLite
  • Bootstrap 5 (CDN)
Proyecto Académico

Desarrollado como entrega evaluativa para demostrar el uso de múltiples aplicaciones, vistas basadas en funciones, rutas dinámicas y consultas ORM en Django.
